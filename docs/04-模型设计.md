# 04 - 模型设计

## 4.1 设计原则

1. **迁移学习优先**：医学数据规模有限，使用 ImageNet 预训练骨干；
2. **模块化**：预处理器、骨干、头部分离，便于替换实验；
3. **多任务可扩展**：共享骨干，按任务挂不同头；
4. **可解释**：内置 CAM 可视化；
5. **可部署**：支持导出 ONNX / TorchScript。

## 4.2 整体结构

```
输入 (B,3,H,W)
   │
   ▼
┌──────────────┐
│  Backbone    │  ConvNeXt / ResNet / DenseNet / ViT
│  (特征提取)   │
└──────────────┘
   │  (B, C, 1, 1) 全局池化
   ▼
┌──────────────┐
│  Dropout     │  p=0.3
└──────────────┘
   │
   ▼
┌──────────────┐
│  FC / Head   │  num_classes 输出
└──────────────┘
   │
   ▼
logits → sigmoid(多标签) / softmax(单标签)
```

## 4.3 骨干网络对比

| 骨干 | 参数量 | 优点 | 缺点 |
| --- | --- | --- | --- |
| ResNet50 | ~25M | 稳定、生态好 | 精度一般 |
| DenseNet121 | ~8M | 医学常用、特征复用 | 显存较高 |
| ConvNeXt-Tiny | ~28M | 精度高、结构现代 | 需较新框架 |
| EfficientNet-B3 | ~12M | 精度/效率平衡 | 调参敏感 |
| ViT-Base | ~86M | 全局建模强 | 需大数据/强增强 |

**默认选择**：`ConvNeXt-Tiny`（精度与部署友好度均衡）。

## 4.4 多标签分类头

```python
class MultiLabelHead(nn.Module):
    def __init__(self, in_features, num_classes, dropout=0.3):
        super().__init__()
        self.drop = nn.Dropout(dropout)
        self.fc = nn.Linear(in_features, num_classes)

    def forward(self, x):
        return self.fc(self.drop(x))   # 返回 logits
```

损失函数（处理类别不平衡）：

```python
criterion = nn.BCEWithLogitsLoss(pos_weight=pos_weight)
```

## 4.5 检测头（肺结节）

- 两阶段：Faster R-CNN + FPN，适合小目标；
- 单阶段：RetinaNet（Focal Loss 处理正负样本不平衡）；
- 需要 3D 信息时：使用 2.5D（相邻切片堆叠）或 3D 卷积。

检出评价用 **FROC** 曲线：在限定假阳性率下衡量灵敏度。

## 4.6 分割头

- U-Net / nnU-Net 经典结构；
- 损失：Dice + BCE 组合；
- 输出病灶掩膜，可叠加到原图。

## 4.7 训练细节

| 项目 | 设置 |
| --- | --- |
| 输入尺寸 | 512×512（分类）/ 512×512 patch（检测） |
| 优化器 | AdamW |
| 学习率 | 1e-4（微调），骨干可更低 |
| 调度 | Cosine + Warmup |
| Batch | 32（视显存调整） |
| 精度 | AMP 混合精度 |
| 正则 | Dropout、权重衰减、早停 |
| 增强 | 随机裁剪、旋转、翻转、亮度/对比度、CLAHE |

## 4.8 推理与后处理

1. 预处理与训练一致（同一归一化参数）；
2. 输出概率经**温度缩放**校准；
3. 阈值：按病种在验证集上优化（最大化 F1 或满足灵敏度要求）；
4. TTA（测试时增强）：水平翻转平均，稳定预测；
5. 不确定性：MC Dropout 多次采样方差，高不确定性转人工。
