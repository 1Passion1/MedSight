# 07 - 部署运维

## 7.1 部署形态

| 形态 | 场景 | 说明 |
| --- | --- | --- |
| 本地/院内服务器 | 数据不出院 | 满足隐私合规，推荐 |
| 私有云 | 多院区 | 集中管理，弹性扩容 |
| 边缘设备 | 低延迟 | 型号较小模型 |

> 医疗数据建议优先**院内私有部署**，避免数据外传。

## 7.2 环境要求

| 项目 | 建议 |
| --- | --- |
| CPU | 8 核以上 |
| GPU | NVIDIA，显存 ≥ 16 GB（推理），≥ 24 GB（训练） |
| 内存 | ≥ 32 GB |
| 存储 | SSD，影像存储按量规划 |
| 系统 | Linux (Ubuntu 20.04+) |

## 7.3 容器化

```dockerfile
FROM nvidia/cuda:12.1.1-cudnn8-runtime-ubuntu22.04
RUN apt-get update && apt-get install -y python3 python3-pip libgl1 && rm -rf /var/lib/apt/lists/*
WORKDIR /app
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY src/ ./src/
COPY configs/ ./configs/
EXPOSE 8000
CMD ["uvicorn", "src.serve:app", "--host", "0.0.0.0", "--port", "8000"]
```

```bash
docker build -t medsight:latest .
docker run --gpus all -p 8000:8000 -v /data:/app/data medsight:latest
```

## 7.4 模型导出与加速

| 方式 | 收益 |
| --- | --- |
| TorchScript | 脱离 Python，稳定部署 |
| ONNX | 跨平台，兼容多种运行时 |
| ONNX Runtime | CPU/GPU 加速 |
| TensorRT | NVIDIA GPU 极致加速 |
| INT8 量化 | 显存与时延下降 |

导出示例：

```python
import torch
model.eval()
example = torch.randn(1, 3, 512, 512).cuda()
torch.onnx.export(model, example, "medsight.onnx",
                  input_names=["input"], output_names=["logits"],
                  dynamic_axes={"input": {0: "batch"}})
```

## 7.5 CI/CD

```yaml
# .github/workflows/ci.yml
name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: "3.10" }
      - run: pip install -r requirements.txt
      - run: pytest -q
```

## 7.6 监控与告警

| 指标 | 阈值示例 | 动作 |
| --- | --- | --- |
| 推理时延 P99 | > 300 ms | 告警 |
| 错误率 | > 1% | 告警 |
| GPU 显存 | > 90% | 扩容 |
| 输入分布漂移 | PSI > 0.2 | 复核模型 |
| 预测分布漂移 | 显著偏移 | 触发再训练评估 |

## 7.7 模型更新与回滚

1. 新模型在离线测试集 + 影子模式验证；
2. 灰度发布（小流量）；
3. 监控指标正常后全量；
4. 异常时一键回滚到上一个版本；
5. 每次上线记录模型版本、数据版本与指标。
