# 08 - 评估与合规

## 8.1 为什么评估与合规至关重要

医疗 AI 的错误会造成真实伤害。模型不仅要在统计指标上达标，还需在**临床有效性、安全性、公平性、可解释性**上经得起检验，并满足监管要求。

## 8.2 模型评估指标

### 分类
| 指标 | 含义 | 关注点 |
| --- | --- | --- |
| AUROC | 排序能力 | 均衡性 |
| AUPRC | 正类精确率-召回 | 不平衡数据 |
| 灵敏度/召回 | 不漏诊 | 筛查场景优先 |
| 特异度 | 不误报 | 减少过度诊疗 |
| F1 | 精确率与召回平衡 | 综合 |
| ECE | 校准误差 | 概率可信度 |

### 检测
- mAP、IoU、**FROC**（肺结节以限定假阳性数下的灵敏度评价）。

### 分割
- Dice、IoU、HD95。

### 临床
- 与医生诊断一致性（Cohen's Kappa）；
- 人机协同下的漏诊率变化；
- 阅片时间/效率提升。

## 8.3 验证设计

| 层级 | 说明 |
| --- | --- |
| 内部验证 | 独立测试集（按患者划分） |
| 外部验证 | 其他中心、其他设备数据 |
| 前瞻性验证 | 真实临床工作流中试用 |
| 亚组分析 | 按年龄、性别、设备、地区分层 |

**关键**：外部验证性能若显著下降，说明泛化不足，须回到数据与模型阶段改进。

## 8.4 公平性与偏差

- 检查不同人群（性别、年龄、种族、设备）性能差异；
- 偏差来源：训练数据不均衡、标注偏见；
- 缓解：平衡采样、公平性约束、亚组重加权；
- 报告：明确披露各亚组性能。

## 8.5 可解释性与人机协同

- 输出热力图/定位，帮助医生理解依据；
- 明确「辅助建议」定位，最终决策归医生；
- 高不确定性样本提示人工复核；
- 避免自动化偏见（医生过度依赖 AI）。

## 8.6 监管合规

| 法规/标准 | 说明 |
| --- | --- |
| NMPA（中国） | 医疗器械软件/SaMD 注册 |
| FDA 510(k)/De Novo | 美国上市前审查 |
| CE / MDR（欧盟） | 欧盟医疗器械法规 |
| IEC 62304 | 医疗器械软件生命周期 |
| ISO 13485 | 质量管理体系 |
| ISO 14971 | 风险管理 |
| HIPAA / 个人信息保护法 | 隐私保护 |

> 若定位为「辅助决策」且不用于独立诊断，监管路径可能不同，但仍需合规论证。

## 8.7 数据与隐私合规

- 伦理审查（IRB）与知情同意；
- 去标识化，符合 HIPAA 安全港或等效标准；
- 遵守《个人信息保护法》《数据安全法》；
- 数据跨境需额外合规评估。

## 8.8 风险管理（ISO 14971 思路）

1. 识别危害（漏诊、误诊、错误建议）；
2. 评估风险（概率×严重度）；
3. 控制措施（人机协同、阈值偏保守、二次确认）；
4. 残余风险沟通（说明书、免责声明）；
5. 上市后监控（不良事件、性能漂移）。

## 8.9 上市后监测

- 持续收集真实世界性能数据；
- 监控模型漂移与不良事件；
- 定期再验证与更新；
- 建立召回/更正流程。

## 8.10 伦理声明

本仓库仅用于**科研与教学**。任何临床使用前，必须完成上述验证与监管审批，并在医生监督下使用。
