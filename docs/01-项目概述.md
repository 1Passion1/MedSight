# 01 - 项目概述

## 1.1 背景

医学影像（X 光、CT）是临床诊断中最重要的信息来源之一。然而：

- 影像科医生数量增长远赶不上影像检查量的增长，阅片工作负荷大；
- 基层医疗机构缺乏有经验的影像医生，诊断水平参差；
- 漏诊、误诊在早期小病灶场景下仍不可避免。

人工智能在图像识别上的突破，使其成为辅助阅片、提升效率与一致性的重要手段。

## 1.2 项目定位

**MedSight** 是一套面向胸部 X 光与 CT 的 AI 辅助诊断研究与工程骨架，目标：

1. 提供**可复现**的数据处理 → 训练 → 评估 → 部署流水线；
2. 提供**完整方案文档**，覆盖需求、算法、数据、架构、合规与项目计划；
3. 作为团队二次开发的起点，而非成品医疗器械。

## 1.3 目标用户

| 角色 | 价值 |
| --- | --- |
| 影像科医生 | 病灶预筛、优先级排序（分诊）、二次确认 |
| 基层医生 | 初步参考建议，降低漏诊 |
| 研究人员 | 可复现基线与实验框架 |
| 产品/管理 | 立项方案与里程碑参考 |

## 1.4 范围

**纳入范围**
- 胸部 X 光：肺炎、气胸、积液、结节等异常识别；
- 胸部 CT：肺结节检测与良恶性分类、病灶分割。

**不纳入范围**
- 直接替代医生出具诊断报告；
- 未获批情况下进入临床工作流；
- 其他科室影像（乳腺、脑部等）暂不覆盖。

## 1.5 关键指标（示例目标）

| 指标 | 目标 |
| --- | --- |
| 主要病种 AUROC | ≥ 0.90 |
| 关键病种灵敏度（高召回） | ≥ 0.95 |
| 单张推理时延（GPU） | ≤ 100 ms |
| 多中心外部验证性能下降 | ≤ 5% |

> 具体阈值需在立项阶段结合临床需求与数据情况确定。

## 1.6 里程碑概览

1. **M1 立项与数据准备**：需求确认、数据合规与标注；
2. **M2 基线模型**：跑通训练评估闭环；
3. **M3 模型优化**：多任务、多中心、性能达标；
4. **M4 系统集成**：推理服务 + 工作站对接；
5. **M5 验证与合规**：临床试验、注册申报准备。
