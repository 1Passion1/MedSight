# 05 - 数据方案

## 5.1 数据来源

| 类型 | 示例公开数据集 | 用途 |
| --- | --- | --- |
| 胸部 X 光 | NIH ChestX-ray14、CheXpert、MIMIC-CXR | 多标签分类 |
| 肺炎 X 光 | Kaggle Chest X-Ray (Pneumonia) | 二分类 |
| 肺结节 CT | LUNA16、LIDC-IDRI | 结节检测 |
| CT 分割 | Medical Segmentation Decathlon | 分割 |

> 使用公开数据集须遵守其许可与引用要求；使用院内数据须通过伦理审查。

## 5.2 数据合规要求

1. **伦理审批**：取得机构伦理委员会（IRB）批准；
2. **去标识化**：删除姓名、ID、检查日期（仅保留相对时间）、设备信息等 PHI；
3. **知情同意**：回溯性研究按法规申请豁免或取得同意；
4. **最小化原则**：仅采集与任务相关的数据；
5. **访问控制**：数据访问留痕、加密存储。

## 5.3 标注方案

- 标注人员：≥2 名资深影像医生 + 1 名仲裁；
- 标注工具：支持分类标签、边界框、分割掩膜；
- 一致性：计算 Kappa/Dice，低于阈值则复核；
- 黄金标准：病理结果 > 多医生共识 > 单医生标注；
- 分级标注：明确「确定/疑似/无」三级，保留不确定性。

## 5.4 数据组织

### 目录方式

```
data/
├── train/
│   ├── NORMAL/          # 二分类示例
│   └── PNEUMONIA/
├── val/
└── test/
```

### CSV 清单方式（多标签推荐）

```csv
image,label1,label2,...,label14
0001.png,0,1,0,...,0
0002.png,0,0,0,...,1
```

## 5.5 数据划分

| 集合 | 比例 | 说明 |
| --- | --- | --- |
| 训练集 | 70% | 参数学习 |
| 验证集 | 15% | 调参、早停、阈值选择 |
| 测试集 | 15% | 最终评估，绝不用于调参 |

**划分原则**：
- 按**患者**划分，防止同一患者跨集合导致泄漏；
- 分层抽样，保证各病种比例一致；
- 外部中心数据单独作为外部测试集。

## 5.6 预处理步骤

1. 读取 DICOM/NIfTI/图像；
2. 去标识化检查；
3. 重采样到统一像素间距；
4. CT 窗宽窗位（肺窗/纵隔窗）；
5. X 光 CLAHE 增强对比；
6. 裁剪黑边、统一到 512×512；
7. 归一化（按数据集均值方差）；
8. 增强（仅训练集）。

## 5.7 数据增强

| 增强 | 说明 |
| --- | --- |
| 随机翻转 | 水平翻转（左右肺解剖近似对称需谨慎） |
| 随机旋转 | ±10° |
| 随机缩放裁剪 | 模拟拍摄差异 |
| 亮度/对比度 | 模拟曝光差异 |
| 高斯噪声 | 提升鲁棒性 |
| Cutout/RandomErase | 防止过拟合 |
| MixUp | 正则化 |

> 注意：医学影像的增强应保持语义合理性，避免破坏解剖结构。

## 5.8 数据质量与版本管理

- **质控**：剔除模糊、截断、伪影严重的影像；
- **去重**：检测重复/近似重复影像；
- **版本**：数据集打版本号（如 `v1.0`），记录来源与划分；
- **清单**：使用 DVC 或哈希清单跟踪数据版本，避免误用。

## 5.9 隐私与安全

- 存储加密（AES-256）；
- 传输 TLS；
- 训练环境隔离，禁止外联；
- 模型不得记忆并反推出个体信息（防成员推断攻击）。
