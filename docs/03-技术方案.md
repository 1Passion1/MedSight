# 03 - 技术方案

## 3.1 总体技术路线

```
原始影像 (DICOM/NIfTI/PNG)
        │
        ▼
┌───────────────────┐
│ 预处理管线         │  去标识化 → 重采样 → 窗宽窗位 → 归一化 → 增强
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 深度学习模型       │  CNN/ViT 骨干 + 分类/检测/分割头
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 后处理与校准       │  阈值调优 → 概率校准 → 不确定性估计
└───────────────────┘
        │
        ▼
┌───────────────────┐
│ 服务与集成         │  推理 API → 可视化 → PACS/RIS → 报告
└───────────────────┘
```

## 3.2 任务与技术选型

| 任务 | 方法 | 代表模型 |
| --- | --- | --- |
| 多标签分类 | CNN/ViT + 多标签 BCE | ResNet、DenseNet、ConvNeXt、ViT |
| 二分类 | CNN + 二分类头 | ResNet50、EfficientNet |
| 目标检测 | Anchor/Anchor-free | Faster R-CNN、RetinaNet、YOLO 系列 |
| 分割 | U 型网络 | U-Net、nnU-Net、U-Net++ |
| 自监督预训练 | 对比学习/掩码建模 | SimCLR、MAE、MoCo |

**推荐起步基线**：
- 骨干：`ConvNeXt-Tiny` 或 `ResNet50`（ImageNet 预训练）；
- 任务：14 类胸部 X 光多标签分类（对标 ChestX-ray14 基准）；
- 损失：`BCEWithLogitsLoss` + `pos_weight` 处理不平衡；
- 优化：AdamW + Cosine 退火 + Warmup；
- 混合精度：AMP。

## 3.3 关键技术点

### 3.3.1 医学影像预处理
- **重采样**：统一像素间距（如 0.5 mm），消除设备差异；
- **窗宽窗位**：CT 用肺窗/纵隔窗，突出目标组织；
- **裁剪黑边**：去除无效背景；
- **CLAHE**：增强 X 光对比度。

### 3.3.2 类别不平衡
- 加权损失（`pos_weight` / `focal loss`）；
- 过采样少数类 / 欠采样多数类；
- 数据增强扩增罕见病样本。

### 3.3.3 泛化能力
- 多中心、多设备数据混合训练；
- 域自适应 / 域泛化（如风格迁移增广）；
- 外部测试集验证。

### 3.3.4 可解释性
- Grad-CAM / Grad-CAM++ 生成热力图；
- Attention 可视化（ViT）；
- 输出置信度与不确定性（MC Dropout / 深度集成）。

### 3.3.5 概率校准
- 温度缩放（Temperature Scaling）；
- Platt Scaling / Isotonic Regression；
- 使输出概率更贴近真实发生率。

## 3.4 训练策略

| 阶段 | 说明 |
| --- | --- |
| 预训练 | ImageNet 迁移学习；数据充足时可自监督预训练 |
| 微调 | 解冻骨干，小学习率微调 |
| 多任务 | 分类 + 检测 + 分割联合训练，共享骨干 |
| 蒸馏 | 大模型蒸馏到小模型，便于部署 |
| 量化 | INT8 量化加速推理 |

## 3.5 评估方法

- **分类**：AUROC、AUPRC、F1、灵敏度、特异度、准确率；
- **检测**：mAP、IoU、FROC（肺结节常用）；
- **分割**：Dice、IoU、HD95；
- **校准**：ECE、Brier Score；
- **临床**：医生一致性（Kappa）、阅片效率提升、漏诊率变化。

## 3.6 技术风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 数据标注噪声 | 性能下降 | 多医生共识、质量控制、标签平滑 |
| 域偏移 | 外部表现差 | 多中心训练、域泛化、持续学习 |
| 过拟合 | 泛化差 | 增强、正则、早停、交叉验证 |
| 长尾病种 | 漏诊 | 重采样、代价敏感学习 |
| 黑盒不可信 | 临床不采纳 | 可解释性 + 校准 + 人机协同 |

## 3.7 技术栈

- **语言**：Python 3.10+
- **框架**：PyTorch、timm、MONAI
- **服务**：FastAPI + Uvicorn
- **部署**：Docker、ONNX Runtime / TensorRT
- **实验管理**：TensorBoard（可扩展至 MLflow/W&B）
